# Support

Use the public support channels only for sanitized, reproducible information.

- Ask usage and integration questions in GitHub Discussions.
- Report a reproducible defect with the bug-report issue form.
- Share a sanitized runtime verification case with the runtime-case form.
- Report vulnerabilities privately according to `SECURITY.md`.

Include ARP version, operating system, architecture, host, expected verdict,
actual verdict, reason codes, and the smallest safe reproduction. Do not include
credentials, environment values, raw argv, private configuration, full command
lines, or proprietary file contents.

Community support is best effort. The Apache-2.0 license contains the governing
warranty disclaimer.
